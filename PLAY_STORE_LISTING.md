## 3. Data Safety Form Answers (Mandatory by Google Play)

When Google Play Console asks you about **Data Safety**:
1. **Does your app collect or share any user data?**
   * Select: **Yes** (because audio is processed for speech recognition).
2. **Audio Data (Voice / Sound Recordings):**
   * Is it collected? **Yes** (Processed ephemerally).
   * Is it shared with third parties? **No**.
   * Is it processed ephemerally (not stored)? **Yes**.
   * Is this data collection required or optional? **Optional** (only when user taps the microphone).
   * Purpose: **App Functionality** (Voice-to-text typing).
3. **Personal Info / Financial Info:**
   * Select: **No**.
4. **Data Encryption:**
   * Does your app encrypt data in transit? Select **Yes** (uses HTTPS/TLS).
5. **Data Deletion:**
   * Can users request data deletion? Select **Not applicable** (no user accounts or stored data).

## 4. Graphics Requirements for Play Store
Before submitting, you need:
1. **App Icon:** 512 x 512 px (PNG or JPEG, up to 1 MB).
2. **Feature Graphic:** 1024 x 500 px (PNG or JPEG).
3. **Phone Screenshots:** At least 2 screenshots (showing the keyboard in action and the setup screen).
